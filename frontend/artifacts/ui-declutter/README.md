# UI declutter screenshots

Screenshots use mocked synthetic claims and are captured at the requested viewport sizes. `before/` records the pre-declutter workspace; `after/` records the revised workspace. The claims queue stays visible beside each workspace view, so the `claims-*` images show the queue alongside the initial Checks panel.

| Department workspace | `before/departments-*.png` | `after/departments-*.png` |
| Management overview | `before/overview-*.png` | `after/overview-*.png` |

Each wildcard has `1024x768`, `1366x768`, and `1920x1080` variants.
